À propos

Cette page est un site statique hébergé gratuitement sur GitHub Pages. Aucun serveur, aucune base de données : le navigateur lit l'API publique de GitHub et affiche les dépôts.

Pour publier un nouveau projet, il suffit d'un git push : la page suit automatiquement.

  • Statique, rapide, sans dépendances
  • Déploiement continu à chaque push
  • HTTPS fourni par GitHub
  • Bilingue français / arabe

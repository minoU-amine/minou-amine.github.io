# حزمة موقع أمين بشيري — دليل الاستخدام

موقع شخصي/تجاري لمونتير فيديو، جاهز للنشر كما هو. لا يحتاج أي تثبيت ولا أي أمر بنّاء (build): الملفات ثابتة وتعمل بمجرد رفعها على أي استضافة.

## محتوى الحزمة

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الواحدة كاملة (عربي/إنجليزي مع زر تبديل اللغة) |
| `styles.css` | كل التصميم، متوافق مع الجوال |
| `app.js` | تبديل اللغة، معرض الأعمال، نوافذ الفيديو، عدّاد الإحصائيات |
| `tracking.js` | إعدادات تتبع Meta + TikTok + GA4 (الملف الوحيد الذي تحتاج تعديله) |
| `fb-events.js` | نسخة احتياطية محلية من مكتبة Meta Pixel (تعمل لو حجب متصفح الزائر السكربت الأصلي) |
| `favicon.svg` | أيقونة التبويب |
| `images/` | الصورة الشخصية + 12 صورة مصغّرة للأعمال + `og-cover.jpg` صورة المشاركة |

## 1) معرّفات التتبع — افتح `tracking.js`

في أعلى الملف كتلة الإعدادات:

```js
metaPixelId:  "1390654969578339",  // معرّف البيكسل
tiktokPixelId:"",                  // اختياري
ga4Id:        "",                  // اختياري
requireConsent: false              // false = تتبع كل زائر مباشرة، بلا بانير
```

- **`metaPixelId`** = الرقم الظاهر في Events Manager → إعدادات مجموعة البيانات → "معرّف مجموعة البيانات".
  ⚠️ ليس رقم حساب الإعلانات الظاهر في الشريط العلوي.
- **`tiktokPixelId`** = من TikTok Events Manager. اتركه فارغاً إن لم تستخدم تيك توك.
- **`ga4Id`** = معرّف Google Analytics 4 بصيغة `G-XXXXXXXXXX`. اتركه فارغاً إن لم تستخدمه.
- **`requireConsent`** مضبوط على `false` حالياً: البيكسل يقلع فور تحميل الصفحة لكل زائر، ولا يظهر أي بانير كوكيز. لا تغيّره إلا إذا أردت إظهار بانير موافقة (قانونياً مطلوب في بعض الدول الأوروبية).

الحقل `currency` داخل نفس الكتلة هو عملة أحداث الشراء (EUR افتراضياً).

## 2) كيف تتأكد أن التتبع يعمل

1. افتح الموقع في تبويب جديد.
2. ثبّت إضافة **Meta Pixel Helper** في كروم (مجانية من Meta).
3. يجب أن يظهر البيكسل أخضر مع حدث `PageView` فوراً.
4. من الهاتف: ضع الطلب في سلة/اضغط زر واتساب، وبعدها افتح Events Manager → "Test Events" — ستظهر الأحداث لحظياً.
5. لتأكيد عدم وجود بانير: افتح Console واكتب `localStorage.getItem('ab_consent_v1')` — يجب أن يكون `null`، مع تحميل `connect.facebook.net/signals/config/...` في تبويب Network.

## 3) صورة المشاركة (واتساب / فيسبوك / لينكدإن)

`index.html` فيه أكواد `og:image` و`twitter:image` تشير إلى:

```
https://79ed81031ca641b3.preview.sana.om/images/og-cover.jpg
```

عند ربط دومينك الخاص (مثلاً `aminebechiri.com`) استبدل هذا الدومين بالدومين الجديد في **4 مواضع** داخل `index.html` (سطور `og:url` و`og:image` و`og:image:secure_url` و`twitter:image`).

بعد النشر على الدومين الجديد، شغّل فحصاً واحداً عبر:
- فيسبوك: developers.facebook.com/tools/debug → الصق الرابط → **Scrape Again**
- واتساب: أرسل الرابط في محادثة مع نفسك لتحديث الكاش
- لينكدإن: linkedin.com/post-inspector

## 4) النشر

**أسهل طريقة — Netlify Drop:** افتح app.netlify.com/drop واسحب مجلد `amine-site` كاملاً بالمتصفح. يعطيك رابطاً فورياً، وبإمكانك ربط دومين من Site settings → Domain management.

**GitHub Pages:** أنشئ مستودعاً، ارفع محتويات المجلد في الجذر، ثم Settings → Pages → Branch: main / root.

**استضافة عادية (cPanel/ftp):** ارفع محتويات `amine-site` إلى `public_html`. تأكد أن `index.html` في الجذر مباشرة لا داخل مجلد فرعي.

⚠️ لا تفتح `index.html` بالنقر المزدوج من جهازك (بروتوكول `file://`) — بعض المتصفحات تحجب التحميل المحلي للخطوط والصور. شغّل خادماً محلياً بأمر `python3 -m http.server` داخل المجلد ثم افتح `localhost:8000`.

## 5) تعديل المحتوى

كل النصوص في `index.html` مكرّرة بالعربية والإنجليزية عبر سمات `data-ar` و`data-en`. عدّل الاثنين معاً لتبقى النسختان متطابقتين. روابط الأعمال هي روابط Google Drive — بدّلها بروابطك الجديدة مع الحفاظ على الصيغة `https://drive.google.com/file/d/المعرّف/view`.

## 6) ملاحظة على الحجم

الحزمة نحو 4.4 ميجا، أغلبها الصور. لو أردت تسريع التحميل حوّل الصور إلى WebP (يبقى المسار `images/work/w1.webp` مع تحديث الامتداد في `index.html`) — يوفّر عادة 60–70% من الحجم.
